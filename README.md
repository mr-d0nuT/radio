# Ràdio

Reproductor web d'emissores de ràdio en directe, amb cercador mundial
(API de [Radio Browser](https://www.radio-browser.info/)), preferides,
i un gadget flotant per damunt de l'escriptori (Document Picture-in-Picture).

Un sol fitxer: `index.html`.

## Notes

- El gadget flotant *always-on-top* només funciona a Chrome/Edge 116+.
  A Safari i Firefox s'obre en una finestra a part; a iOS no està disponible.
- En servir-se per HTTPS, les emissores que només emeten per `http://`
  queden bloquejades pel navegador i es marquen amb el distintiu `HTTP`.
